# 🌐 Web Testing

## 📌 О разделе

В разделе собраны учебные работы по тестированию веб-приложений.

---

## 🛒 Sima-Land

Учебный проект по тестированию маркетплейса Sima-Land.

В рамках проекта были подготовлены:

- тест-кейсы;
- чек-листы;
- позитивные и негативные проверки;
- проверки основных пользовательских сценариев;
- UI-проверки;
- кросс-браузерное тестирование;
- тестирование доступности.

➡️ [Открыть материалы Sima-Land](./sima-land/)

## 👤 Sedtest Tools

Учебный проект по тестированию веб-приложения `market.sedtest-tools.ru`.

В рамках проекта выполнялось тестирование объекта «Пользователь»:

- авторизация;
- регистрация;
- редактирование данных пользователя;
- позитивные и негативные сценарии.
