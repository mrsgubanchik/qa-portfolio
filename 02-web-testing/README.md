# 🌐 Web Testing — Sima-Land

## 📌 О проекте

Учебная работа по тестированию веб-приложения Sima-Land.

В рамках проекта были подготовлены:

- тест-кейсы;
- чек-листы;
- позитивные и негативные проверки;
- проверки основных пользовательских сценариев;
- UI-проверки;
- кросс-браузерное тестирование;
- тестирование доступности.

---

## ✅ Тест-кейсы

В тест-кейсах рассматривались сценарии:

- регистрация нового пользователя;
- авторизация пользователя;
- редактирование данных пользователя;
- авторизация через различные способы;
- негативные сценарии авторизации и регистрации.

---

## 📋 Чек-листы

Подготовлены проверки для:

- регистрации пользователя;
- авторизации пользователя;
- редактирования пользователя;
- поиска товара;
- фильтрации товаров;
- добавления товара;
- доставки и возврата;
- работы с корзиной;
- оформления заказа;
- заказа товара;
- оплаты товара;
- отправки и получения товара;
- UI;
- кросс-браузерности;
- доступности.
