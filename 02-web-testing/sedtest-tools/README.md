# 👤 Sedtest Tools

## 📌 О проекте

Учебный проект по тестированию веб-приложения `market.sedtest-tools.ru`.

В рамках проекта выполнялось тестирование объекта «Пользователь»:

- авторизация;
- регистрация;
- редактирование данных пользователя;
- позитивные и негативные сценарии.
