# ✅ Тест-кейсы — Sedtest Tools

**Объект тестирования:** объект «Пользователь» на сайте `market.sedtest-tools.ru`.

## Позитивные тесты

### 1. Авторизация пользователя с ранее зарегистрированным E-mail и паролем

**Предварительные условия**

1. Открыт сайт http://market.sedtest-tools.ru/
2. Подготовлены логин и пароль зарегистрированные в системе

**Шаги**

| № | Шаг |
|---:|---|
| 1 | Справа вверху нажать "Войти" |
| 2 | Ввести в поле E-mail или телефон "test@test.ru" |
| 3 | Ввести в поле Пароль "test123" |
| 4 | Нажать кнопку Войти |

**Ожидаемый результат**

Авторизация прошла успешно, открыта главная страница
