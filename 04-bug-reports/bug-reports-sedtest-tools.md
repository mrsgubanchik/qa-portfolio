\# 🐞 Баг-репорты — Sedtest Tools

\#\# API / TechStore

\#\#\# BR-01. Не отображается "productId" в ответе на запрос при добавлении нового товара

\*\*Приоритет\*\*

Нормальный

\*\*Описание\*\*

Согласно инструкции, в ответе после запроса отображается "productId" с численным значением.

\*\*Предусловия\*\*

1\. URL: http://techstore.sedtest-tools.ru:5000/api/products  
2\. Метод: POST  
3\. Пользователь авторизован, имеет права администратора

\*\*Шаги воспроизведения\*\*

1\. В Body ввести данные нового товара  
2\. Нажать Send

\*\*Ожидаемый результат\*\*

Некорректные данные. Проверьте email, пароль и имя. 400 Bad Request

\*\*Фактический результат\*\*

"message": "Товар успешно создан", "productId". 201 Created

\#\#\# BR-02. Отсутствует валидация полей в форме при регистрации нового пользователя

\*\*Приоритет\*\*

Высокий

\*\*Серьезность\*\*

Значительная

\*\*Описание\*\*

Поля email, password и name принимают невалидные значения. Также пробелы не считаются лишним символом, и пользователя можно зарегистрировать только с данными из пробелов.

\*\*Предусловия\*\*

1\. Метод: POST  
2\. Подготовлены данные для регистрации

\*\*Шаги воспроизведения\*\*

1\. В Body ввести данные с пробелами в обязательных полях  
2\. Нажать Send

\*\*Ожидаемый результат\*\*

Некорректные данные. Проверьте email, пароль и имя. 400 Bad Request

\*\*Фактический результат\*\*

Пользователь успешно зарегистрирован. 201 Created

\#\# Market Sedtest Tools

\#\#\# BR-20. Отсутствует кнопка "Редактировать" для объявлений во вкладке "Не активные"

\*\*Приоритет\*\*

Высокий

\*\*Серьезность\*\*

Значительная

\*\*Описание\*\*

Кнопка "Редактировать" под объявлениями во вкладке "Не активные" отображается только при переходе на вкладку "Активные".

\*\*Предусловия\*\*

1\. Открыт сайт http://market.sedtest-tools.ru/account  
2\. Пользователь авторизован  
3\. Во вкладке "Мои объявления" → "Не активные" добавлены объявления

\*\*Шаги воспроизведения\*\*

1\. Перейти во вкладку "Не активные"  
2\. Перейти во вкладку "Активные"

\*\*Ожидаемый результат\*\*

Кнопка "Редактировать" отображается под объявлением

\*\*Фактический результат\*\*

Кнопки "Редактировать" нет. Действия с объявлением невозможны.
