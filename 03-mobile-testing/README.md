# 📱 Mobile Testing — Облако Mail.ru

## 📌 О проекте

Учебная работа по функциональному тестированию мобильного приложения «Облако» от mail.ru.

В рамках проекта были подготовлены чек-листы для проверки:

- реакции приложения на жесты;
- распознавания лица;
- ориентации экрана;
- покупок;
- совместимости;
- подключения к сети;
- производительности;
- прерываний;
- удобства использования.
