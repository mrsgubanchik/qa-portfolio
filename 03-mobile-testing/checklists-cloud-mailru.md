## Реакция на жесты

### ✅ Позитивные тесты

1. Открыть приложение касанием
2. Свернуть приложение смахиванием вверх
3. Использовать жест Scroll для простотра файлов галереи

5. Открыть файл касанием
6. Закрыть файл смахиванием вниз
7. Просмотр файлов смахиванием вправо и влево

11. Исполльзовать жесты при низкой производительности устройства

### ❌ Негативные тесты
